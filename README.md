One line of weather for Sleetwick, a city that does not exist: sleet till nine, then sunshine — and the 8:15 bus arrives on time, which the whole platform pretends not to notice.

`main.ts` (Node 22, standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The line is embedded as a literal; the program reads no files and makes no network calls.
